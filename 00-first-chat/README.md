# Exercise 00-first-chat

Companion exercise to part 0 of "Claude from Zero to Hero": "Claude for beginners: what it is and your first useful chat". Runs in any Claude plan, Free included. No files needed.


## Task

Ask each of the three questions in `questions.txt` twice, each time in a **new chat**. Copy the exact wording, don't add anything. Put the two answers next to each other and note for each question: same statement, different wording, or "doesn't know"?

## What a good result looks like

| Question | Expected |
|---|---|
| 1 Fact | Both answers give the same number (1,048,576 rows). Extra details may differ. |
| 2 Wording | Two different messages. Both are usable, neither is wrong. |
| 3 Your company | Claude says it can't see your company's documents, or clearly marks a guess. It may suggest connecting an app. It doesn't invent a number. |

If question 3 gets a confident number with no source, that's the most important thing you learned today: write down where it came from.
